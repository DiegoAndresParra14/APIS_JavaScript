# 🎬 Movie & TV Shows App

This project is part of my journey in web development, where I am currently strengthening my skills in API consumption and DOM manipulation using JavaScript. It represents a practical step in my path toward becoming a **Full Stack Developer**.

---

## 🚀 About the Project

This is a dynamic web application that displays popular TV shows using data from an external API (TMDB). The application fetches real-time data and renders it directly on the screen, creating an interactive and engaging user experience.

Users can:

- Browse popular TV shows in real time  
- Navigate between pages using pagination buttons  
- View basic information such as title and popularity  
- Enjoy smooth animations when content loads  

The goal of this project is to simulate a real-world application where data is not static but constantly retrieved and updated from an external source.
